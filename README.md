# Wazuh SIEM & Security Monitoring Lab

**A Hands-on Cybersecurity Monitoring Project**

This repository documents my personal Wazuh SIEM lab, deployed on Kali Linux with multiple Windows and Linux endpoint agents.

The project explores centralized security monitoring, log analysis, custom detection rules, File Integrity Monitoring (FIM), vulnerability detection, and security alert investigation.

## Project Overview

The lab demonstrates practical exposure to defensive cybersecurity concepts through a centralized Wazuh deployment and multi-platform endpoint monitoring.

## Lab Environment

| Component | Configuration |
|---|---|
| Central Host | Kali Linux |
| SIEM Platform | Wazuh |
| Deployment | All-in-One |
| Endpoints | Windows and Linux |
| Monitoring | Centralized endpoint monitoring |

## Key Features

- Wazuh all-in-one deployment
- Multi-platform endpoint monitoring
- Centralized log monitoring
- Custom detection rules
- File Integrity Monitoring
- Vulnerability detection
- Security alert investigation
